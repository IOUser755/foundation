# AI Agents

This directory contains definitions and specifications for various AI agents used in the development process.

## Available Agents

### Development Agents
- [Frontend Developer](agents/frontend-developer.md) - Specializes in frontend development tasks
- [Backend Architect](agents/backend-architect.md) - Designs and implements backend architecture
- [API Tester](agents/api-tester.md) - Performs API testing and validation

### Operations Agents
- [DevOps Automator](agents/devops-automator.md) - Automates deployment and infrastructure tasks
- [Performance Benchmarker](agents/performance-benchmarker.md) - Conducts performance testing and optimization

## Usage

Each agent definition includes:
- Role and responsibilities
- Skills and capabilities
- Example prompts and workflows
- Best practices
