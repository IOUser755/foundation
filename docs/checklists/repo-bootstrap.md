# Repository Bootstrap Checklist

1. Create repo from template (or copy from foundation)
2. Add .github/workflows/ci.yml (copy or re-use template)
3. Add CODEOWNERS paths mapped to real teams
4. Enable branch protection & required checks (lint, typecheck, test)
5. Enable secret scanning, dependency review, Dependabot alerts
6. Create dev, staging, prod environments
7. Add LICENSE; decide DCO/CLA if needed
